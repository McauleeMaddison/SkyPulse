# Local device check

The signed Release build for runtime `f71eb7d` was installed over the existing
SkyPulse app and launched successfully on the paired iPhone 17 Pro Max. It used
the existing bundle ID and local build number 18; the app was not uninstalled.

The user then reported gaps at pipe-cap joins, insufficient LED motion and an
unappealing pointed scenery style. **Device acceptance did not pass.** The
subsequent pipe/scenery follow-up must be checked on the phone again.

The app-only Instruments performance attempt timed out waiting for the device
to boot, despite its successful launch. No frame-rate, thermal or sustained-memory
result was obtained. No screen recording was collected, no capture permission was
changed and no Apple upload was made.
