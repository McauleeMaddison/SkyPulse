# SkyPulse handoff

Repository: https://github.com/McauleeMaddison/SkyPulse — branch `main`.

1. Open `mobile/` in Unity Hub and `Assets/Scenes/SkyPulse.unity`.
2. Open this repository in VS Code; use the [editing guide](EDITING_GUIDE.md).
3. Review the [current local visuals and test record](Development/Current/README.md).
4. Keep the [installed Build 21 checklist](Release/DeviceBuild21/DEVICE_CHECKLIST.md)
   separate from the new local source. The new source is not installed on iPhone.
5. After owner visual approval, build a new numbered candidate and perform device
   checks for gameplay, frame pacing, memory, heat, audio and retained progress.

The approved flight controls and Voltcrest-style wing sampler are retained. New
progression is cosmetic, reuses the existing daily reward transaction and does not
change flight stats or crystal prices. Four optional daily cases use the existing
optical rules. Historical review material is under `Development/Archive`.

**Do not submit for public App Review.** The owner is waiting for Apple's response
about the earlier similarity/account allegation. Do not claim it has been resolved.
