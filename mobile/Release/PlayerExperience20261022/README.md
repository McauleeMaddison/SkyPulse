## Player-facing changes

- **Homes:** open dimensional stages replace the dark support slabs and duplicate dock. Home controls use calmer satin surfaces. Transparent render targets use correct premultiplied compositing. Eight Blackout beacons reflect the existing saved system completions.
- **Flight:** original collider-matched pipes now have smooth cylinder normals, restrained machined seams, brighter titanium reflections and the same world key colour as the bird. The result screen no longer draws a Home stage over the score. Flight width, forces, spacing and collisions are unchanged.
- **Bird rewards:** the report separates actual pickup value, Tech bonuses and bird-trait bonuses. Collector activations have a concise pickup cue. The displayed subtotals reconcile with the existing once-only wallet credits; there are no new reward amounts or save keys.
- **Tech Tree:** the connected 3D branches and direct two-axis drag remain. Every point says LEVEL 1/2/3 and Installed, Next with its discounted price, or Locked. Large rectangular label plates are removed. Only the next upgrade receives a light glass capsule and small optical marker; installed/locked points use floating text. The 37 generous touch areas remain stationary and disjoint.
- **Signal Heist:** each vault restores a named city system. Mirrors have titanium clamps and thin open light arcs, source/uplink receivers are faceted, and raised optics cast soft contact shadows. Quiet telemetry and rounded glass controls replace the heavy frames. Normal taps still rotate immediately.
- **Planning:** tap Plan, then a prism to evaluate its next turn using the real rules. Dashed blue beams and the preview summary show the predicted network; ROTATE shows the exact trace cost, including three-trace sensor outcomes. Confirm once or close the plan without spending. The top telemetry remains the live state; the preview is explicitly identified below the board. Pause/restart clears speculative paths. Completion still saves once and activates the next vault immediately.
